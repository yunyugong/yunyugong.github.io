# YYG Blog

Live website: https://yunyugong.github.io/

Bilingual Markdown blog with light/dark mode and PDF attachment previews.
Articles and referenced PDFs are exported from the local author desk.
Account files, passwords, browser drafts, and unreferenced PDFs remain local.

To update: run Export for GitHub.cmd locally, then upload the files listed in
publish-manifest.json to the main branch. GitHub Pages deploys from the root.

Third-party licenses are in vendor/.
